## KI-001 活动外部拖动中反复关闭与呼出

- **状态**：延期；2026-09-05 归档，留待后续宿主/OLE 生命周期专项处理。
- **现象**：从 Explorer 发起的外部拖动仍活动时，呼出 Vok 后再次关闭会重新暴露源目录；一次测试中，带 Ctrl 修饰的拖动在源目录松开后生成了同目录 `.lnk` 副本。
- **当前基线**：按用户要求恢复到报告该问题前的 M3.MVP3 行为；不保留“拖动时禁止关闭”的临时修正、对应回归测试或 DWM/OLE Gate 探针。Stage 本身不复制、移动或删除源文件。
- **已排除方向**：关闭请求失效可避免源目录变化，但不满足交互；DWM cloak 实测 33/33 次使 OLE 命中离开目标 HWND，不能作为不可见拖放 shield。
- **后续入口**：重新处理时必须在隔离候选上同时证明“可关闭/可再次呼出、源目录零变化、OLE 终态单次、跨代隔离”；不得以固定延时、忽略 `DragLeave` 或键态猜测代替终态。
- **保留现场**：测试产生的副本属于用户文件，未经授权不删除；详细诊断报告仅保留在 Git 忽略的 `.artifacts/` 中。
