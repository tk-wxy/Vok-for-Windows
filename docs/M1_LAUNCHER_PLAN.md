# 主界面 1:2:1 静态设计基线

## 本轮目标

本轮只重构界面，不实现功能。主页面参考 Workbench 的整体层级，并严格采用：

```text
┌──────────────────── 顶部搜索预留（56 DIP）────────────────────┐
├──────── 启动台 1 ────────┬──────── 中转站 2 ────────┬── 剪贴板 1 ──┤
│     静态占位应用卡片      │          留空            │      留空     │
└────────────────────── 底部单行（36 DIP）─────────────────────┘
```

## 区域契约

| 区域 | 尺寸/比例 | 本轮内容 |
|---|---:|---|
| 顶栏 | 56 DIP | 左侧 Vok 标识、中间最大 480 DIP 搜索框预留、右侧现有设置入口 |
| 左侧启动台 | `1*` | 24 DIP 分区标题；八个静态占位应用卡片仅用于建立视觉密度 |
| 中间中转站 | `2*` | 24 DIP 分区标题，内容区完全留空 |
| 右侧剪贴板 | `1*` | 24 DIP 分区标题，内容区完全留空 |
| 底栏 | 36 DIP | 状态、当前快捷键和版本保持为一行 |

三列必须使用星号权重，不用固定像素近似 1:2:1。纵向采用 `56 / * / 36`，各区域采用 `24 / *`：框架行使用固定 DIP 保持视觉密度，内容区吸收 Per-Monitor V2 换算后的剩余有效高度，不按1080p/2K/4K原始像素分档，也不整体缩放页面。现有设置面板继续在同一主 HWND 内覆盖整个页面，不新增顶层窗口。

## 明确不实现

- 搜索输入、筛选或编辑器焦点；
- 启动台点击启动、右键菜单、拖拽排序或持久化；
- 中转站的数据、空状态提示、按钮或命令；
- 剪贴板的数据、空状态提示、按钮或命令；
- 为上述视觉占位创建 ViewModel、服务或业务状态。

后续任何功能必须由用户单独确认范围后再作为纵向切片设计，不能从本轮静态卡片或分区名称推断实现授权。
